# daylitica.com

Marketing site for **Daylitica, LLC** — public-opinion research. Plain static
HTML/CSS, hosted on GitHub Pages (deploys from `main`, root).

Pages: `index.html` (company) · `support.html` (PollShot support) ·
`privacy.html` (privacy policy — the App Store privacy-policy URL points here).

The PollShot product site lives in its own repo (`pollshot-site` → pollshot.com)
and links back here for company, support, and privacy.

History note: extracted 2026-07-11 from `pollshot/sites/daylitica` (subtree
split, original commits preserved).
